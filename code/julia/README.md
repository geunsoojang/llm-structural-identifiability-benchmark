# Generated Model Scripts

StructuralIdentifiability.jl starter scripts generated from `models.csv` plus direct PDF checks for the papers supplied by the user.

Folders are organized by paper ID. Each compatible model script runs the same two baseline checks:

1. unknown initial conditions
2. known initial conditions for all model state variables

Some paper models are marked as source-adapted or not directly compatible in `models.csv`; those folders include README notes or adapted scripts instead of claiming a final formal result.

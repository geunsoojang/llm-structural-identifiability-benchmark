For the following ODE model, determine the structural identifiability of each unknown parameter from the observed output. Do not use tools or code; reason from the model equations only.

ODE system:
S'(t) = -beta*S(t)*I(t)/N
L'(t) = beta*S(t)*I(t)/N - alpha*L(t)
I'(t) = alpha*L(t) - gamma*I(t)
R'(t) = gamma*I(t)

State variables:
S(t), L(t), I(t), R(t)

Unknown parameters:
alpha, beta, gamma, N

Known constants or inputs:
none

Initial conditions:
S(0), L(0), I(0), R(0) are unknown.

Population constraints:
N = S(t) + L(t) + I(t) + R(t) for all t

Observed output:
y1(t) = alpha*L(t)

Assumptions:
The observed outputs are available continuously over a time interval and are noise-free.
All model parameters and population sizes are positive, and all initial conditions are nonnegative.
The population constraints hold exactly, so the population sizes are constant but unknown.

Report:
1. Classify each unknown parameter as globally identifiable, locally identifiable, or non-identifiable.
2. If individual parameters are non-identifiable but identifiable combinations exist, state those combinations.

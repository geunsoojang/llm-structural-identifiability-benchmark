For the following ODE model, determine the structural identifiability of each unknown parameter from the observed output. Do not use tools or code; reason from the model equations only.

ODE system:
S'(t) = -beta*S(t)*I(t)/N - ell*beta*S(t)*H(t)/N - beta_prime*S(t)*P(t)/N
E'(t) = beta*S(t)*I(t)/N + ell*beta*S(t)*H(t)/N + beta_prime*S(t)*P(t)/N - kappa*E(t)
I'(t) = kappa*rho1*E(t) - (gamma_a + gamma_i + delta_i)*I(t)
P'(t) = kappa*rho2*E(t) - (gamma_a + gamma_i + delta_p)*P(t)
A'(t) = kappa*(1 - rho1 - rho2)*E(t) - gamma_a*A(t)
H'(t) = gamma_i*(I(t) + P(t)) - (gamma_r + delta_h)*H(t)
R'(t) = gamma_a*(I(t) + P(t) + A(t)) + gamma_r*H(t)
F'(t) = delta_i*I(t) + delta_p*P(t) + delta_h*H(t)

State variables:
S(t), E(t), I(t), P(t), A(t), H(t), R(t), F(t)

Unknown parameters:
beta, beta_prime, delta_h, delta_i, delta_p, ell, gamma_a, gamma_i, gamma_r, kappa, rho1, rho2

Known constants or inputs:
N

Initial conditions:
S(0), E(0), I(0), P(0), A(0), H(0), R(0), F(0) are unknown.

Observed output:
y1(t) = I(t) + P(t) + H(t)
y2(t) = delta_i*I(t) + delta_p*P(t) + delta_h*H(t)

Assumptions:
The observed output variables are available continuously over a time interval and are noise-free.
All parameters are positive, and initial conditions are nonnegative.
All state initial conditions are unknown and nonnegative.

Report:
1. Classify each unknown parameter as globally identifiable, locally identifiable, or non-identifiable.
2. If individual parameters are non-identifiable but identifiable combinations exist, state those combinations.
